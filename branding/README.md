# BinLab Engineering — identidade visual

## Arquivos

- `logo.svg`: logotipo horizontal vetorial, escalável e com fundo transparente.
- O símbolo combina um hexágono estrutural, um circuito/processor e uma forma geométrica inspirada na letra B e no prompt de terminal.
- Paleta principal: azul-ciano, azul profundo, prata e branco.
