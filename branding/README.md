# BinLab Engineering — identidade visual

## Arquivos canônicos

- `logo.svg`: logotipo horizontal vetorial para fundos escuros; fundo transparente.
- `logo-light.svg`: variante horizontal para fundos claros, com wordmark e tagline em azul-escuro para manter contraste.
- Os dois arquivos são vetoriais, escaláveis, autossuficientes e não carregam fontes ou recursos externos.
- O símbolo combina um hexágono estrutural, um circuito/processador e uma forma geométrica inspirada na letra B e no prompt de terminal.

## Uso e consistência

- Selecione a variante conforme a superfície; não aplique filtros que reduzam contraste.
- Preserve proporção, área de respiro e integridade do símbolo.
- Não redesenhe, distorça, rotacione ou substitua cores sem registrar a alteração.
- Para ícones pequenos, prefira uma versão reduzida do símbolo, sem wordmark; não reduza o logotipo horizontal até comprometer a leitura.
