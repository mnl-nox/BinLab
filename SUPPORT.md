# Suporte

## Antes de solicitar ajuda

1. Consulte o [README](README.md) e a documentação em [docs/](docs/).
2. Verifique as [issues abertas](https://github.com/mnl-nox/BinLab/issues) para localizar relatos ou propostas existentes.
3. Informe a versão do BinLab, sistema operacional, arquitetura, comando executado e saída relevante.
4. Remova tokens, caminhos privados, dados pessoais e conteúdo proprietário antes de publicar logs.

## Bugs e solicitações

- Defeitos reproduzíveis: abra uma issue usando o formulário de bug.
- Novas capacidades: use o formulário de solicitação de funcionalidade.
- Dúvidas de uso: abra uma issue com contexto mínimo, versão e passos já tentados.
- Vulnerabilidades: não abra issue pública; siga [SECURITY.md](SECURITY.md).

## Escopo de suporte

A versão 0.3.2 prioriza Python 3.8+, Linux x86_64 para os pacotes binários e a fundação Web executada localmente. Consulte o README para limitações de distribuição e recursos planejados. Não há garantia de compatibilidade com todas as distribuições Linux ou arquiteturas.
