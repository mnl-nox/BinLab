# Política de segurança

## Reporte responsável

Não publique detalhes de uma vulnerabilidade explorável em issue pública. Abra um reporte privado pelos recursos de Security Advisories do GitHub deste repositório, quando habilitados. Inclua versão/commit afetado, impacto, pré-condições e passos mínimos para reproduzir sem dados de terceiros.

## Escopo de segurança

O BinLab deve tratar arquivos e entradas externas como não confiáveis. A inspeção é estática por padrão. Não execute arquivos importados automaticamente.

## Suporte

Correções serão priorizadas conforme impacto, reprodutibilidade e versões mantidas. Até a publicação de uma política formal de versões suportadas, consulte o estado da branch principal e as releases disponíveis.
