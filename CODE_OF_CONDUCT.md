# Código de Conduta

## Nosso compromisso

Como participantes, mantenedores e contribuidores, comprometemo-nos a tornar a participação no BinLab Engineering uma experiência profissional, respeitosa e livre de assédio, independentemente de experiência, identidade, origem, condição pessoal ou trajetória técnica.

## Comportamento esperado

- Use linguagem respeitosa e objetiva.
- Critique ideias, implementações e decisões técnicas; não ataque pessoas.
- Forneça contexto reproduzível ao relatar bugs e divergências.
- Reconheça contribuições e atribua corretamente trabalhos de terceiros.
- Preserve a privacidade e não publique credenciais, dados pessoais ou informações sensíveis.
- Mantenha discussões técnicas focadas no escopo do projeto.

## Comportamento inaceitável

Assédio, discriminação, ameaças, insultos direcionados, exposição de dados privados, spam, intimidação e publicação deliberada de conteúdo malicioso ou irrelevante não são aceitos.

## Aplicação

O mantenedor do projeto pode editar, ocultar ou remover conteúdo que viole este código e restringir temporária ou permanentemente a participação de responsáveis por violações. A decisão deve considerar a gravidade, o contexto e a recorrência.

Para reportar uma violação, utilize os canais privados disponíveis nas ferramentas de segurança/moderação do GitHub para este repositório. Não transforme denúncias sensíveis em issues públicas.

Este código se aplica a issues, pull requests, revisões, discussões e demais espaços oficiais do projeto.
